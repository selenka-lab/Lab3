# 2D Physics: CCD и Multi-rate

## Зависимости
- C++17
- SFML 3.0.2 (Graphics, Window, System)

## Сборка

### Windows
1. Установить SFML.
2. Создать проект в Visual Studio.
3. Добавить все исходные файлы.
4. Подключить SFML (Graphics, Window, System).
5. Собрать и запустить.

## Управление

| Клавиша | Действие                          |
|---------|-----------------------------------|
| 1       | Режим CCD                         |
| 2       | Режим Multi-rate                  |
| T       | Режим сравнения                   |
| R       | Сброс сцены                       |
| G       | Включение и выключение гравитации |

## Расположение в коде
### Vector2.h
1. Структура Vector2
2. Математика векторов: сложение, вычитание, умножение на число, скалярное произведение, длина
### PhysicsWorld.h
1. Структуры CircleBody и Wall
2. Объявление класса PhysicsWorld
3. Все публичные и приватные методы симуляции
### PhysicsWorld.cpp
1. Создание сцены (reset)
2. Дискретные столкновения со стенами и между шарами
3. Столкновения между обычными и быстрыми объектами
4. CCD
5. Multi-rate обновление
6. Гравитация
7. Обработка клавиш
8. Отрисовка
9. Замер времени шага физики
10. Формирование заголовка окна
### Lab3.cpp
1. Создание окна
2. Главный цикл программы
3. Передача событий в PhysicsWorld
4. Вызов обновления физики и отрисовки
